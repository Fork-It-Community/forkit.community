Étudiant à 42, j'apprends un métier qui change pendant que je l'apprends. J'ai d'abord refusé l'IA pour apprendre « à l'ancienne », avant de comprendre que je ratais un virage. J'ai aussi fini par supprimer un projet entier parce que je ne comprenais plus le code qu'elle avait écrit.

À travers ce parcours, ce talk pose une question que tous les devs se posent : quelle place pour l'humain quand la machine code plus vite que nous ?

Ma conviction : l'IA est l'occasion de redéfinir notre rôle. Moins produire du code, davantage comprendre le besoin, penser produit et architecture, et trouver notre vraie valeur ajoutée dans un projet.
